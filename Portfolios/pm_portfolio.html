A · ACTION
01

하이브리드 프로덕션 방법론 (Waterfall + Agile)

상위 계획은 Waterfall, 실행은 Agile로 분리. Milestone / Initiative는 Waterfall로 명확한 목표·달성 기준, Epic / Task / Subtask는 Agile로 반복 수행. Vertical Slice → Alpha → Beta → Shipping까지 단계별 달성 필요 사항을 정의.

02

Task Management System (Airtable)

Jira 대신 Airtable로 자유도 높은 TMS를 구성. Objective → Epic → Task → Subtask 위계 세팅, 리스크 체크(자체 중요도 · 연관성 · Plan B 유무)와 빠른 PoC → QA → 이터레이션 루프를 내장.

03

커뮤니케이션 체계 정비

회의 전 Agenda 사전 공유 · 발산/수렴 성격 미리 정의 · Action Item 추출 중심 운영. 회색 영역(담당자가 애매한 업무)을 식별해 프로젝트화하는 것도 이 단계의 루틴.

04

게임 기획 직접 수행 (UE5)

담당 기획자가 없는 피처를 직접 기획하고 UE5에서 프로토타이핑:

  • · 파쿠르 시스템 — 상태 전이 다이어그램 + 상세 기능 명세서 → 유관 부서 킥오프 → 구현 → 이터레이션
  • · 레벨 디자인 — 약 2시간 플레이타임 규모의 필드 동선/클라이밍 루트, 30분 분량 던전 레벨(기믹·연출 포함)
  • · 연출 프리비즈 — UE5 BP · 카메라 · 시퀀서로 인게임 타이밍과 느낌을 사전 구현 → 실 작업자가 퀄리티를 높여 마무리
R · RESULT

QA 기능 테스트 → 수정 → 최종 확인 —
릴리즈 베타 등록 → 라이브 배포 옵션별 분기

사업팀뿐 아니라 제휴처 담당자와 직접 소통 — 제작 진행 공유, 필요 정보(레퍼런스 · 라이선스 가이드라인) 요청, 일정 조율까지 PM이 허브 역할을 수행.

R · RESULT
  • "어디까지 됐어요?" 커뮤니케이션 비용 대폭 감소 — 수치적으로 진행률·일정을 볼 수 있는 현황판 확보
  • 20+건의 제휴 프로젝트에 동일 템플릿 적용, 프로세스 안정화
  • 새 프로젝트 착수 시 스케줄링 소요 시간 단축
CASE 05 · PERSONAL

TIKIT —
PM이 직접 빌딩한 AI 서비스.

코드를 백지부터 쓸 줄 모르는 PM이 AI 에이전트와 함께 기획 · 개발 · 브랜딩 · 배포까지 혼자 완수한 0→1 케이스.

기획 · 개발 · 브랜딩 · 운영 (1인) 2025 ~ 운영 중 🔗 tikit.day
S · Situation

"PM이 AI만으로 실제 작동하는 프로덕트를 어디까지 만들 수 있을까?" 코드를 처음부터 작성할 줄은 모르지만, 코드를 읽고 흐름을 이해하는 기술 이해도를 갖고 있었습니다. AI 에이전트와의 협업으로 이 간극을 메우는 도전.

T · Task

딱딱한 초대장 도구를 넘어, 일상의 모임을 소장하고 싶은 "티켓"으로 만드는 서비스를 구현. 마일스톤 단위 목표: M1 PoC → M2 Brand → M3 GTM.

A · ACTION
M1

기술 검증

AI 에이전트(Gemini → Claude Code)와 페어 프로그래밍으로 핵심 기능 구현. 단순 코드 생성을 넘어, "익명 유저가 가입하면 기존 데이터를 어떻게 마이그레이션할 것인가"와 같은 정책 설계를 직접 수행.

M2

브랜딩 + 프로덕션 파이프라인

브랜드명(TIKIT) · 슬로건(Let's Tikit a day) · 도메인(tikit.day) 확정. v0로 컴포넌트 디자인, Vercel 배포, GitHub 기반 CI/CD. Claude Code(Web) + Vercel 조합으로 모바일에서도 [코드 수정 → PR → 리뷰 → 머지 → 배포]가 가능한 1인 무제한 이터레이션 환경 구축.

M3

PM 역할 전 과정 수행

  • · 핵심 기능 정의 → 테스트 → 수정의 반복
  • · 백로그 관리 및 우선순위 결정
  • · 운영 리스크(부적절 콘텐츠) 대응 정책 설계
  • · 데이터 수집 구조 설계 — "다음에 무엇을 할지" 결정할 근거 마련
R · RESULT
  • tikit.day 런칭 완료, 링크드인 공유를 통한 초기 피드백 수집
  • 프론트/백엔드 아키텍처 · 보안(권한 관리) · 렌더링 최적화 · API 연동까지 기술적 시야 확장
  • "기술은 AI가 보완하지만, 기술이 어디로 향해야 할지 결정하고 논리의 구멍을 찾는 건 기획자의 몫" — PM 본질 재확인
